# Porsche Sales Analytics Dashboard

Dashboard interativo desenvolvido a partir de uma base de dados de vendas de veículos Porsche, com foco em **exploração de dados, indicadores de negócio e visualização analítica**.

O projeto foi pensado para transformar uma base tabular em uma experiência de análise próxima à de um ambiente de Business Intelligence profissional.

> **Acesse o projeto online:** [https://naldo42.github.io/porsche-dashboard/](https://naldo42.github.io/porsche-dashboard/)

---

## Preview do Dashboard

O dashboard utiliza uma interface escura, minimalista e elegante, inspirada na identidade visual da marca Porsche.

*(O projeto conta com gráficos interativos de distribuição de pagamentos, barras de progresso dinâmicas por categoria e indicadores de volume).*

---

## Objetivo do Projeto

O objetivo principal é responder a perguntas de negócio estratégicas a partir dos dados de vendas, permitindo análises como:

* Quais são os modelos com maior volume de vendas?
* Como as vendas se distribuem por diferentes regiões/cidades?
* Quais são os meios de pagamento mais utilizados pelos clientes?
* Qual é a volumetria de registros filtrados em tempo real?

Além de responder a perguntas específicas, a aplicação permite explorar livremente os dados por meio de filtros dinâmicos.

---

## Principais Recursos

* **KPIs Dinâmicos:** Indicadores de resumo em tempo real (como contagem total de registros e faturamento).
* **Filtros Interativos:** Segmentação por dimensões de negócio (modelo, ano, cidade, meio de pagamento).
* **Seção de Insights:** Área dedicada a destacar automaticamente padrões relevantes encontrados nos dados filtrados.
* **Design Responsivo:** Interface limpa baseada em tema escuro (Dark Mode) com ótima legibilidade.

---

## Tecnologias Utilizadas

* **HTML5 / CSS3:** Estrutura e estilização da interface de usuário.
* **JavaScript:** Manipulação de dados, lógica de filtros e interatividade.
* **Chart.js:** Construção de gráficos dinâmicos e responsivos.
* **GitHub Pages:** Hospedagem estática e publicação online do projeto.
